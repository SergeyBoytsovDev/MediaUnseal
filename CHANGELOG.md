# Changelog

## 1.4.0

- Added stream muxing with container-aware format selection, stream copy where compatible, and a preview of the processing plan.
- Added PGS and VobSub extraction and reopening, matching DVD IFO metadata, and optional Tesseract OCR export to existing text subtitle formats.
- Improved OCR timeline recovery, partial export reporting, and dependency installation.
- Added progress per track, theme-aware preview artwork, language flags, and copy support for multiple Diagnostic Report entries.
- Improved FFmpeg error presentation and diagnostics, Opus multichannel compatibility, and process cleanup.
- Published the packaged CLI as Native AOT alongside the desktop app.

See the [v1.4.0 release notes](packaging/RELEASE_NOTES_1.4.0.md) for details.
