# Track Extractor

**Track Extractor** — настольная программа для извлечения, преобразования и управления медиапотоками в видео-, аудиофайлах и других мультимедийных контейнерах.

Приложение позволяет работать с видеодорожками, звуком, субтитрами, изображениями, обложками и анимациями через единый графический интерфейс — без необходимости самостоятельно составлять команды FFmpeg.

**Технологии:** C# · .NET 10 · Avalonia UI · FFmpeg · FFprobe

> **Статус проекта:** активная разработка. Первая тестовая Portable-сборка для Windows x64 создана и проверена. Официальная версия 1.0 ещё готовится.

## Возможности

### Извлечение медиапотоков

Track Extractor анализирует выбранный файл и отображает обнаруженные потоки с доступной технической информацией.

Поддерживаются следующие категории:

| Категория | Возможности |
|---|---|
| **Видео** | Извлечение видеопотока без звука, преобразование в другие поддерживаемые форматы |
| **Аудио** | Извлечение звуковых дорожек, преобразование между аудиоформатами |
| **Субтитры** | Извлечение и преобразование совместимых форматов субтитров |
| **Изображения** | Извлечение встроенных изображений и преобразование отдельных файлов |
| **Обложки** | Обнаружение и извлечение обложек из поддерживаемых медиаконтейнеров |
| **Анимации** | Работа с анимированными изображениями, преобразование в другие анимационные и совместимые видеоформаты |

Доступность конкретной операции зависит от контейнера, характеристик потока и возможностей установленного FFmpeg.

### Извлечение без перекодирования

Для совместимых потоков предусмотрен режим **«Исходный»**, позволяющий сохранить оригинальные данные без повторного кодирования.

Это обеспечивает:

- высокую скорость обработки;
- отсутствие дополнительных потерь качества;
- сохранение исходного кодека, когда это поддерживается;
- минимальную вычислительную нагрузку.

Если пользователь выбирает другой формат, программа выполняет необходимое преобразование.

### Конвертация

Для каждой категории предусмотрены отдельные настройки выходного формата.

**Видео:** MP4, MKV, MOV, WebM, AVI и другие поддерживаемые контейнеры.

**Аудио:** WAV, FLAC, MP3, AAC и другие совместимые форматы.

**Субтитры:** SRT, ASS и другие поддерживаемые текстовые форматы.

**Изображения:** JPEG, PNG, BMP, TIFF, WebP, QOI и другие поддерживаемые форматы.

**Анимации:** GIF, APNG, анимированный WebP и преобразование в совместимые видеоформаты.

Для каждой категории доступны соответствующие параметры обработки и выбор совместимого кодировщика.

Программа использует возможности установленного FFmpeg, поэтому некоторые форматы и кодировщики могут отсутствовать или иметь ограничения.

### Работа с несколькими потоками

Можно выбирать необходимые потоки и обрабатывать их в рамках одной очереди.

Например, из фильма с несколькими звуковыми дорожками и субтитрами можно извлечь:

- видеодорожку без аудио;
- оригинальную и локализованную аудиодорожки;
- необходимые субтитры;
- встроенную обложку, если она обнаружена и поддерживается.

### Анализ медиафайлов

С помощью FFprobe программа получает доступные характеристики:

- контейнер и кодеки;
- длительность;
- разрешение видео и изображений;
- частоту кадров;
- частоту дискретизации аудио;
- количество аудиоканалов;
- битрейт, если он определён;
- языки и другие метаданные потоков.

Для поддерживаемых файлов отображается миниатюра содержимого.

## FFmpeg и FFprobe

Track Extractor использует **FFmpeg** для обработки и преобразования медиаданных, а **FFprobe** — для анализа файлов и потоков.

Программа проверяет наличие необходимых компонентов и предусматривает помощь с их получением, если они отсутствуют.

Поддержка кодеков, контейнеров и аппаратного ускорения зависит от используемой сборки FFmpeg и оборудования компьютера.

При работе с программой необходимо учитывать лицензионные условия FFmpeg и его зависимостей.

## Начало работы

1. Запустите Track Extractor.
2. Перетащите медиофайл в окно программы или нажмите **«Выбрать файл»**.
3. Дождитесь завершения анализа.
4. Отметьте необходимые потоки.
5. Выберите выходные форматы — либо оставьте **«Исходный»**.
6. При необходимости откройте **«Настроить»** и укажите параметры кодирования.
7. Укажите папку сохранения.
8. Нажмите **«Обработать»**.
9. После завершения проверьте полученные файлы.

Для извлечения без потери качества рекомендуется сохранять исходный поток без перекодирования, если выбранный формат поддерживает такую операцию.

|---|---|

## Сборка из исходного кода

При наличии доступа к исходному проекту и установленного .NET SDK 10:

```powershell
dotnet restore .\TrackExtractor.csproj
dotnet build .\TrackExtractor.csproj -c Release
```

### Тестовая Portable-сборка для Windows x64

```powershell
dotnet publish .\TrackExtractor.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -o "$env:USERPROFILE\Desktop\TrackExtractor-Portable"
```

Для создания ZIP-архива:

```powershell
Compress-Archive -Path "$env:USERPROFILE\Desktop\TrackExtractor-Portable" -DestinationPath "$env:USERPROFILE\Desktop\TrackExtractor-Portable.zip" -CompressionLevel Optimal -Force
```

Это промежуточный способ публикации приложения, а не окончательная схема официального релиза.

**Примечание:** отсутствие установщика не гарантирует хранение всех пользовательских данных исключительно внутри папки программы. Полноценный Portable-режим является отдельным требованием к выпуску.

## Известные ограничения

Track Extractor находится в разработке. Не все комбинации форматов и кодировщиков гарантированно совместимы.

В частности:

- некоторые контейнеры имеют ограничения по поддерживаемым кодекам;
- доступность аппаратного кодирования определяется оборудованием и FFmpeg;
- не все встроенные ресурсы MKV пока поддерживаются для извлечения;
- графические субтитры нельзя автоматически преобразовать в текстовые без распознавания текста (OCR);
- некоторые форматы изображений и анимаций требуют отдельной проверки совместимости;
- полноценная поддержка Linux и macOS ещё должна пройти практическое тестирование.

Наличие формата или кодировщика в FFmpeg само по себе не гарантирует успешную обработку любого файла этого типа.
