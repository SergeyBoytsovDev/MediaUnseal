# Media Unseal 1.2.2 — Debian and Fedora release check

These are reproducible **manual test instructions**. For version 1.0.0, the user reported successful launches on Debian 13 and Fedora 45 under WSL2, and media processing with FFmpeg on Debian 13 under WSL2. These are not native Linux host tests, and the full procedure below has not been independently completed on both systems. Use an x86-64 Debian or Fedora desktop with an X11 session or working XWayland, a non-root user, and a disposable media file containing video and audio. The archive bundles .NET 10; do not install a separate .NET runtime just to test it. FFmpeg and FFprobe are external tools and must be installed separately for media processing.

1. On the target system, install missing desktop libraries. Avalonia lists X11, ICE, SM and Fontconfig as required; .NET uses ICU for globalization. Debian 13: `sudo apt install libicu76 libfontconfig1 libx11-6 libice6 libsm6`. Fedora: `sudo dnf install libicu fontconfig libX11 libICE libSM`. Chinese, Japanese and Korean fonts are optional: Debian `fonts-noto-cjk`, Fedora `google-noto-sans-cjk-fonts`. The .NET native runtime can additionally need glibc, libgcc, OpenSSL, libstdc++, time-zone and Kerberos libraries. Use `ldd` below to confirm the exact installed system, rather than assuming every dependency is present.
2. Copy `MediaUnseal-1.2.2-linux-x64.tar.gz` to the system. Compare `sha256sum MediaUnseal-1.2.2-linux-x64.tar.gz` with the release checksum. Run `tar -tzf MediaUnseal-1.2.2-linux-x64.tar.gz >/dev/null` and `tar -tvzf MediaUnseal-1.2.2-linux-x64.tar.gz | grep '/MediaUnseal$'`; expect executable mode `-rwxr-xr-x`.
3. Extract with `tar -xzf MediaUnseal-1.2.2-linux-x64.tar.gz` and enter `MediaUnseal-1.2.2-linux-x64`. Check `file MediaUnseal`, `ldd ./MediaUnseal`, `ldd ./libSkiaSharp.so`, `ldd ./libHarfBuzzSharp.so`, and `ldd ./libcoreclr.so`. Record any `not found` lines. Do not set `LD_LIBRARY_PATH` globally.
4. Confirm `command -v ffmpeg` and `command -v ffprobe`; install them using the distribution's normal package manager if absent. Start with `./MediaUnseal` from a graphical login. Check that the window opens and closes without a fatal error, and record Debian/Fedora version, architecture, session type (`echo "$XDG_SESSION_TYPE"`), and any stderr output.
5. Open a disposable video file with at least one audio track. Confirm file analysis, thumbnail, stream categories, and selectable tracks. Extract one video and one audio stream to a writable directory; confirm output files and play/probe them. Start a longer operation, cancel it, and check that no partial final file remains. Change a harmless setting, close, relaunch, and confirm it persists.
6. Open the language settings and check that Russian plus nine translated interface languages are available. Open the media guide and confirm it loads. Test both a small and a multi-track file. On a clean second user account, repeat launch and a basic export to detect assumptions about a pre-existing home configuration.

The application uses Avalonia's X11 backend on Linux. A Wayland desktop therefore needs XWayland unless a suitable backend is configured. SkiaSharp's standard Linux native asset requires fontconfig. See [Avalonia supported platforms](https://docs.avaloniaui.net/docs/supported-platforms), [SkiaSharp native packages](https://github.com/mono/SkiaSharp/blob/main/documentation/dev/packages.md), and [.NET Linux requirements](https://learn.microsoft.com/en-us/dotnet/core/install/linux). Record actual `ldd` and run results separately for Debian and Fedora; cross-publishing from Windows does not prove runtime compatibility.
